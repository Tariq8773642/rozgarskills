MS Word Kaise Seekhein

Complete Beginner Guide

MS Word Microsoft کا ایک مشہور word-processing software ہے جسے documents بنانے، applications لکھنے، letters تیار کرنے، CV بنانے، tables بنانے اور documents کو PDF میں تبدیل کرنے کے لیے استعمال کیا جاتا ہے۔ اگر آپ computer کے beginner ہیں تو MS Word سیکھنا آپ کے لیے بہت فائدہ مند skill ہے۔

MS Word کیا ہے؟

MS Word کی مدد سے ہم مختلف قسم کے documents آسانی سے بنا سکتے ہیں، مثلاً:

  • Job applications
  • Official letters
  • CV / Resume
  • Reports
  • School assignments
  • Business documents
  • Tables اور مختلف forms

MS Word کیسے شروع کریں؟

MS Word کھولنے کے بعد Blank Document پر click کریں۔ آپ کے سامنے ایک خالی page آ جائے گا۔ اب آپ keyboard سے English typing شروع کر سکتے ہیں۔ اگر آپ Urdu typing کرنا چاہتے ہیں تو Windows میں Urdu keyboard enable کرکے Urdu میں بھی typing کی جا سکتی ہے۔

Text کو Bold، Italic اور Underline کرنا

MS Word میں text کو واضح اور خوبصورت بنانے کے لیے formatting options استعمال کیے جاتے ہیں۔ Bold text کو موٹا، Italic text کو ترچھا اور Underline text کے نیچے لائن لگاتا ہے۔

Font اور Font Size

آپ text کا Font اور Font Size تبدیل کر سکتے ہیں۔ Heading کے لیے نسبتاً بڑا font اور عام paragraph کے لیے مناسب چھوٹا font استعمال کرنا بہتر ہے۔

Paragraph Alignment

MS Word میں text کو چار طریقوں سے align کیا جا سکتا ہے:

  1. Align Left
  2. Center
  3. Align Right
  4. Justify

Official letters اور documents میں مناسب alignment استعمال کرنے سے document زیادہ professional نظر آتا ہے۔

MS Word میں Table بنانا

Table بنانے کے لیے Insert → Table پر click کریں اور اپنی ضرورت کے مطابق rows اور columns منتخب کریں۔

MS Word میں Picture شامل کرنا

Document میں تصویر لگانے کے لیے Insert → Pictures پر click کریں اور computer سے picture select کریں۔ Picture کو select کرکے اس کا size کم یا زیادہ کیا جا سکتا ہے۔

Page Setup

Layout menu سے Margins، Orientation اور Paper Size وغیرہ تبدیل کیے جا سکتے ہیں۔ عام documents کے لیے A4 size استعمال کیا جاتا ہے۔

Document Save کرنا

اپنا کام ضائع ہونے سے بچانے کے لیے document کو وقتاً فوقتاً save کرتے رہیں۔ Keyboard سے Ctrl + S دبا کر document save کیا جا سکتا ہے۔ پہلی مرتبہ save کرتے وقت file کا نام اور location منتخب کریں، مثلاً My CV.docx۔

MS Word Document کو PDF میں تبدیل کرنا

Final document دوسروں کو بھیجنے کے لیے PDF format مفید ہوتا ہے۔ عام طور پر File → Save As → PDF کے ذریعے document کو PDF میں save کیا جا سکتا ہے۔

Beginners کی عام غلطیاں

  • Document کو save نہ کرنا
  • بہت زیادہ مختلف fonts استعمال کرنا
  • Headings کو واضح نہ کرنا
  • Paragraph کی spacing خراب رکھنا
  • Document کا backup نہ رکھنا
  • ہر جگہ بہت زیادہ formatting کرنا

Conclusion

MS Word سیکھنا computer beginners کے لیے ایک اہم skill ہے۔ اگر آپ job، office work، data entry، clerical work یا online work کرنا چاہتے ہیں تو MS Word کی basic knowledge آپ کے لیے بہت فائدہ مند ہوگی۔ روزانہ تھوڑی سی practice کے ذریعے آپ typing، formatting، tables، applications، CVs اور PDF documents بنانا سیکھ سکتے ہیں۔
